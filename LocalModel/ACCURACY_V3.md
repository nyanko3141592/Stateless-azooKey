# 精度改善 v3 — 日本語側の境界を利用

比較対象は直前の `bf0888d`。学習済みモデルの重み・語彙を変えず、日英の区間選択を改善しました。入力履歴や言語モードを参照せず、現在の未確定文字列だけで判定します。

## 今回の変更

1. 日本語側が辞書の語、または語＋助詞として明確に終わる場合は、未知の英語候補をより広く比較。
2. 未知語の開始位置を選ぶ際、日本語側の形態的な根拠を加点。`kono｜namespace` を `kononame｜space` にする誤分割を抑制。
3. 未知語の終端が既知の英単語を横切る候補を除外。`codereview` を `co｜de｜review` のように壊す退行を防止。
4. 同一入力比較テストに、旧版が正解だった完成文を新版が不正解にしたら失敗する条件を追加。

加点は未知英語への境界だけに適用します。日本語全体への加点も試しましたが、`summaryni` の `ni` を英語へ取り込む退行があったため採用しませんでした。

## 完成文と入力途中を別々に比較

「完全一致」は全文字の日英ラベルの一致。漢字の変換精度ではありません。「英語破損」は完成済み英語区間を日本語へ割り当てた途中入力数。「反転」は既入力文字の言語ラベルが変わった打鍵数で、正しく直った変更も数えます。

|---|---:|---:|---:|
| 既存96文 | 96→96 | — | — |
| 既存36文 | 35→35 | 18→18 / 771 | 106→106 |
| 前回80文 | **71→77** | **186→104 / 883** | 183→188 |
| 以前の24文 | 22→22 | 6→6 / 243 | 85→81 |
| 今回追加48文 | 45→46 | 67→54 / 533 | 247→245 |

**前回80文では反転が5回、最終24文では1回増えています。** 完成文と英語保護は改善しましたが、あらゆる入力で表示の揺れが減ったとはしません。比較した各セットで、旧版が正解だった完成文を不正解にした例はありません。

## 評価の扱い

全て自作の小規模診断であり、実利用ログや独立した自然文ベンチマークではありません。テンプレート・語彙の重複があります。

- 前回80文は今回は開発用。結果を使って境界評価を調整しました。
- 今回48文は12語×2混在テンプレート、英語12文、日本語8文、保護領域4文。最初に実装を固定して測定後、別の既存24文の退行を修正して再測定。最終値を厳密な未使用テストとは呼びません。
- 最終24文はその退行修正後に追加し、推論を固定してから測定。12語×2テンプレートです。結果を見た後に推論の追加修正はしていません。
- `final-inference.sha256` に、最終24文の評価前に固定した推論とモデルのハッシュを保存。
